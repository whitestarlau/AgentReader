# AgentReader 需求文档 v0.1

> 生成时间：2026-08-30 | 状态：草案 | 基于讨论共识

## 1. 项目概述

AgentReader 是一个**桌面端** AI 文档阅读工具，支持 PDF / EPUB 文档的导入、管理、阅读与 AI 对话。核心交互为**在文档上画线高亮、矩形框选**，将选中内容作为上下文与 AI 进行讨论。设计理念参考 `Reference/pi` —— 麻雀虽小五脏俱全：分层清晰、可扩展、会话可持久化。

## 2. 产品形态

- **形态**：桌面应用，Electron
- **平台**：macOS 优先，兼顾 Windows / Linux
- **离线能力**：文档阅读与标注离线可用；AI 对话需联网（预留本地模型扩展）

## 3. 用户角色与场景

- **研究者/学生**：精读论文，划重点、框图表，向 AI 提问“这段公式什么意思？”
- **职场人阅读**：长报告/合同，框选条款让 AI 解释风险、总结要点
- **通用读者**：EPUB 图书阅读，划线做笔记并与 AI 讨论

核心流程：`导入文档 → 浏览阅读 → 高亮/框选 → 侧边栏 AI 对话 → 标注与对话持久化 → 导出/回顾`

## 4. 功能需求

### 4.1 文档图书馆（导入式管理）

- [ ] **导入**：用户主动导入 PDF/EPUB，应用内部创建独立文件夹统一管理，不污染原文件
- [ ] **存储结构**：每文档一文件夹 `library/{docId}/`
  - `original.pdf|epub` 原文件（只读）
  - `doc.json` 元数据（标题、作者、页数、导入时间、hash、封面）
  - `annotations.json` 标注列表
  - `chats.jsonl` 对话历史（JSONL 追加，参考 Pi Session）
  - `vectors.db` 向量索引（RAG 阶段）
  - `thumbnails/` 缩略图
- [ ] **图书馆视图**：列表/网格、搜索、标签、最近阅读、删除（连带文件夹）
- [ ] **打开方式**：仅能打开已导入文档，不直接关联系统文件双击

### 4.2 文档渲染与阅读

- [ ] **PDF 渲染**：基于 PDF.js，支持翻页、连续滚动、缩放、目录、文本选择、搜索
- [ ] **EPUB 渲染**：基于 epub.js，支持章节导航、流式排版、字体/主题调节
- [ ] **通用能力**：页码/进度、书签、全屏、深色模式

### 4.3 标注系统（核心）

- [ ] **高亮文本**：选中文本 → 高亮（多色），保留 `page、rects、text、颜色`
- [ ] **矩形框选**：拖拽画框，适用于图文/表格/公式，保留 `page、bbox、截图、OCR 文本`
- [ ] **标注管理**：点击标注高亮对应区域、修改颜色/删除、标注列表侧栏、按页/时间筛选
- [ ] **数据模型**：见 §6

### 4.4 AI 对话

- [ ] **侧边栏对话**：常驻右侧，类似 ChatPDF，支持多轮
- [ ] **选中即上下文**：当前高亮/框选自动注入为引用块，用户无需手动复制
- [ ] **分级上下文**（用户可选）：
  - L1 仅选中片段（默认，最省 token）
  - L2 选中 + 前后页/章节
  - L3 全文 RAG（向量检索相关段落）
- [ ] **快捷问**：选中后气泡 `解释 / 翻译 / 总结 / 提问`（MVP 可先为按钮模板）
- [ ] **对话持久化**：每个文档独立会话树，支持分支/回溯（复刻 Pi JSONL + parentId）
- [ ] **引用追溯**：AI 回答可回跳到原文位置

### 4.5 AI 能力（通过 Tool 实现）

- 解释、总结、翻译、提问、对比、批判、生成笔记
- 后续扩展为 Agent Tool：`searchDoc`, `readPage`, `summarizeChapter` 等，AI 自主调用

### 4.6 多提供商支持（复刻 pi-ai）

- [ ] 统一 `Model / Context / StreamFn` 抽象
- [ ] 支持 OpenAI / Anthropic / Google / 兼容接口切换
- [ ] API Key 管理、模型选择、流式输出

### 4.7 扫描版 PDF（OCR + 截图双轨）

- [ ] **双轨策略**：有文本层用文本，无文本层用截图
- [ ] **OCR 预处理**：导入时对图片型页面跑 OCR，生成可检索文本
- [ ] **视觉模型**：框选区域截图直接丢给多模态模型
- [ ] **降级**：OCR 失败时自动走截图路径

### 4.8 导入导出

- [ ] 导出标注为 Markdown / JSON
- [ ] 导出带标注的 PDF（将高亮写入标准 PDF 注释）
- [ ] 导入/导出会话

## 5. 非功能需求

- **性能**：1000 页 PDF 流畅滚动，标注 <100ms 响应
- **文本精度**：PDF.js 文本层坐标误差 <2px
- **AI 流式**：首字 <1.5s，支持中断/重试
- **数据安全**：本地优先，API Key 加密存储（Electron safeStorage）
- **可扩展**：预留 extensions 目录，支持后续插件

## 6. 数据模型草案

```ts
Annotation {
  id: string
  docId: string
  type: 'highlight' | 'rect'
  page: number
  rects: { x,y,w,h }[]   // PDF.js 归一化坐标 0-1
  text?: string
  screenshot?: string    // rect 截图 base64/path
  color: string
  createdAt: number
}

ChatMessage {
  id: string
  role: 'user'|'assistant'
  content: string
  context: { annotationIds: string[], level: 'selection'|'chapter'|'full' }
  createdAt: number
}
```

## 7. MVP 范围（v0.1）

**做**：Electron + PDF.js + 高亮/矩形 + 侧边栏对话（选中/章节两档）+ 单兼容接口 + 图书馆文件夹 + chats.jsonl 持久化
**不做**：EPUB、RAG 全文检索、OCR 双轨、扩展系统、多提供商全量、导出 PDF 注释

## 8. 非目标

- 不做云同步、协作、多人标注（后续）
- 不做 PDF 编辑（仅阅读+标注）
- 不直接打开系统文件，必须导入

## 9. 验收标准

- 导入 PDF 后可在 library 文件夹看到完整结构
- 文本可选、高亮与框选均可创建并持久化，重启后恢复
- 选中内容能在侧边栏作为上下文与 AI 流式对话
- 扫描版 PDF 不崩溃（MVP 可提示不支持而非报错）
